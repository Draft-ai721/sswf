共创 · 设计 AI 工作坊 — HTML 独立版

1. 用电脑上的 Chrome 或 Edge 打开“共创设计工作坊.html”。
2. 页面样式、图形、三维查看器和 SKP 转换脚本均已内嵌，无需访问原网站。
3. 项目文字、原文件和转换结果保存在当前浏览器的 IndexedDB，不与线上账号同步，也不会自动共享给其他设备或其他人。清理浏览器数据可能删除这些记录。
4. SKP 原文件上限 20 MB，转换期间保持页面打开。兼容性以实际解析为准。
5. AI 提纲与点评仍为明确标注的教学示例；没有真实 AI 服务。学生/教师角色为本机演示视图。
6. 若浏览器禁止本地文件使用存储或后台进程，请用本地静态服务器打开（在此文件目录运行 python -m http.server 8000，然后访问 http://localhost:8000/共创设计工作坊.html）。
7. HTML 文件本身包含应用，不包含你线上账号已经上传的私人模型和项目数据。

独立版基于当前已制作的网站导出，使用 Three.js 与 OpenSKP 1.5.0。第三方许可证位于配套压缩包 licenses 目录。
