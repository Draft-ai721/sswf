# 可视化共创工具与设计参考

本次继续保持“多元共创工作台”，把资料整理、空间推演、候选生成和真实评审连接起来。沿用已有账号、项目、上传文件、DeepSeek 服务、SQLite持久卷及评审授权。

## 项目看板

从侧栏“项目看板”或六阶段顶部进入。可新增想法、来源链接，或引用项目文件、调研发现、备选方案和讨论。引用卡片随原始记录更新；“补充已有成果”按实际项目数据整理，不进行AI调用，不伪造材料。

卡片支持六阶段拖放、左右箭头移动、搜索及材料展板视图。图片仅使用当前项目上传的JPG/PNG缩略图，参考链接由用户主动打开，不由服务器抓取。链接仅允许HTTP/HTTPS且不能包含用户名密码。移出看板保留原记录；删除原调研发现或方案时同步清理看板引用，旧快照保留。每项目最多120张卡片。

## 功能需求与空间推演

先在第三阶段填写功能名称、数量、单项面积，然后在“空间推演”创建方案。每次放置一个功能实例，平面格网1格为1米，拖动按0.5米吸附；选中空间可使用方向键移动，Enter打开侧栏尺寸编辑。宽、深与高度可独立调整。可以查看由空间块投影形成的体块示意并导出SVG。

界面动态计算实例数量、缺少数量、空间面积与需求面积差，标记矩形重叠和画布越界。面积按矩形求和，重叠仍计入，不作为总建筑面积。单层概念布局不含墙厚、结构、门窗和法定审查。

相邻与分隔意图由学生设置功能对、距离和理由，按两类功能所有实例的最近矩形边距比较；尚未放置时显示待布置。关系线连接最近的两个实例。距离满足仅指符合用户输入的几何条件，不能证明声学、交通或消防表现。

每个备选方案最多80个空间块。复制方案形成独立布局，保留来源；第四阶段比较显示实际空间面积、缺少数量、重叠与越界，并保留学生自评和选择理由。修改功能清单会更新各方案指标；删除功能时清理对应工作稿空间及关系，既有快照不变。

## AI生成可编辑布局

已有正数面积的功能清单即可从空间推演发起，无需先手工布置。填写本次目标、讨论视角和画布，明确点击生成后才调用服务。功能需求总实例数最多24个，画布宽深1至1000米，单次结果为一个可编辑矩形空间布局。

请求使用实际保存的功能ID、数量、面积、空间关系、六阶段记录及选定附件。模型输出经后端校验，拒绝未知功能、超需求实例、无效数值或越界。重叠、缺少和面积差在结果及推演中明确显示，仍需学生判断和修改。

结果先审阅，再保存到阶段候选区。采用时必须填写理由，系统创建新的备选方案，原始候选、模型、材料来源和几何数据继续保留。普通项目保存不能伪造或覆盖AI候选。材料改变时拒绝直接套用旧生成；采用已保存布局时，功能引用仍须有效。复用既有个人/全站限额、幂等、超时及无自动重试策略。

## 版本评审与图纸定位

保存包含看板和布局的快照，再创建评审室。可邀请教师、同伴或使用者作为评审者，或邀请只读访客。邮箱绑定与账号身份确认要求沿用已有机制。

受邀评审者可在报告内针对具体方案提问，在JPG/PNG图纸上点击具体位置，或继续使用原有模型三维定位。坐标绑定共享版本，服务器校验来源、图片类型和0至1的归一化坐标。PDF可先选页转图片，再保存快照参与定位讨论。实际登录账号的称呼与邀请视角同时显示，外部伪造身份请求头不能覆盖。

问题列表可按全部、未解决、待复核和已完成筛选。学生回应后进入待复核，授权评审者可继续修改或复核完成。只读访客不能发表意见，撤销或到期的成员不能继续访问。图纸始终显示该版本全部定位点，已完成批注用不同颜色标记。

看板、空间布局、关系与原始候选随阶段快照持久保存；导出报告保留布局示意、来源与讨论。重启沿用原有卷及加密密钥，不重建数据库。旧客户端省略新增看板、关系和布局字段时，后端保留已有数据。
