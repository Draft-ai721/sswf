# 画布与设计助手

## 学生的最短路径

1. 登录后点“新建项目”，直接进入空白画布。项目名称可在顶部随时改，任务书和六阶段文字均可后补。
2. 点“＋空间”、选阅读/交流等快捷类型，或在助手中输入“加一个20㎡交流区”。
3. 点选空间，拖动移动、拖动右下角缩放，也可直接修改浮动工具条的名称或面积。方向键按0.5米微调，Delete删除。画布的＋/−放大缩小，空白处拖动平移，“全图”复位。
4. 复杂的组织与修改问题可直接问助手。当前方案和选中空间自动成为上下文，无需再次填写阶段、视角、生成目标等表单。
5. 点“邀请评审”保存固定版本，再创建评审室。版本说明可后补，空白说明会明确标注“关键设计理由待学生补充”。创建后仍需选择受邀者，项目保持私人访问权限。

桌面为左侧对话、中央画布、可选侧栏；手机通过“画布 / AI助手”切换。材料、过程、讨论和精确属性按需打开。六阶段不再作为逐步填完的入口门槛，旧的完整阶段编辑器仍可从“过程”进入。项目看板、真实SKP、图纸、版本导出和课程任务保留在项目工具里。

## 操作和依据

- 本地执行：添加/删除/复制空间、明确的面积或百分比调整、复制方案、面积/重叠/越界计算。普通画布操作不扣AI次数。
- 模型执行：复杂需求、布局建议和意图理解继续使用现有网站DeepSeek配置与每日额度，不要求学生填写个人API。模型只能返回白名单中的添加/修改/删除/复制空间、复制方案、项目命名和需求记录，单次最多10项。后端检查对象归属、尺寸、画布边界及当前数据版本后才写入。未知对象应提出一个必要问题，禁止执行任意脚本或代替用户公开/邀请/确认设计。
- 数字由几何程序计算。空间调整仅改该实例；原任务面积和其他实例不被修改。手动画出的功能条目标记为sketch，不能解释成任务书要求。
- 所有AI操作保留运行编号、原始请求、实际来源、模型及应用时间。“原始依据与操作”可查看。AI模拟意见与真人评审分别保存。
- 发送范围在输入框下展开查看：当前项目课程、阶段信息、当前方案/选择及至多3份主动关联材料。只发送最近6条历史用户/助手消息，不发送别的账号项目或服务器内部的验证副本。实际读取能力按每份来源的readStatus标明。
- PDF上传先保留原件，再由本地PDF.js提取前10页内、最多12000字符文字，不占模型次数。提取文字可给助手整理需求；扫描件、复杂排版、完整图纸几何并不等于被读取，必须核对原件。扫描件可继续使用原图纸工具选页转图。

## 撤销与保存

手动操作和成功写入的AI操作共用每个项目当前页面会话内的25步历史，Ctrl/Cmd+Z撤销，Ctrl/Cmd+Shift+Z或Ctrl+Y重做。AI批量修改作为一步撤销。

撤销只恢复设计工作稿，不删除原件、生成记录、快照或评审反馈。刷新页面后会话撤销历史结束，已保存工作稿和固定版本仍在。若从旧编辑入口改动了工作稿，撤销拒绝覆盖不匹配内容。请求AI期间仍可手动编辑；若依据发生变化，该AI结果不会覆盖新修改。请求失败保留画布、不自动重试。保存状态显示在顶部，项目工具提供“保存 / 重试保存”。

## 可复现验证与边界

2026-11-21本轮验证：

- `npm run build:railway`后运行`npm test`：128项通过，含新增9项画布/助手测试。覆盖空项目、需求与实例分离、无效操作原子拒绝、方案副本、明确中文指令、撤销保留反馈、其他入口改动冲突、AI动作验证、真实会话鉴权及来源过期拒绝。
- `npm run test:browser`：使用本机Chromium，1440×1000和390×844尺寸，12个流程组通过。实际鼠标拖动和角点缩放、撤销/重做、PDF原件上传及本地文字读取、对话动作写入、方案复制、AI批次撤销、请求期间手动编辑、失败不重试、六阶段往返、手机无页面横向溢出、固定版本与真实私人评审室均验证。可设置`CHROME_BIN`；输出截图与结果在`artifacts/studio-qa/`，该目录不提交仓库。
- 浏览器与后端测试均使用受控模型响应，调用真实本地鉴权、保存、验证和应用路径；不消耗生产模型额度，不能据此宣称真实模型总能理解需求或设计质量已通过专业审查。

仍需实际学生/教师的独立验证：提供真实课程任务书和未整理的原始材料，让学生在无指导情况下完成“开始方案→修改空间→问AI→邀请同伴”任务；记录首次有效编辑时间、完成率、求助次数、误操作及恢复情况。用原版与新版同等任务比较，并请不参与开发的建筑教师核对面积、任务符合性与方案解释。当前没有开展这轮真实用户研究，也没有声称达到某个提速比例。

本画布是单层矩形概念推演，不包含墙厚、结构、完整门窗、消防审查或BIM施工图生成。真人评审与专业判断继续负责这些结论。
