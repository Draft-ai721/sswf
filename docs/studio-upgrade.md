# 共创工作坊：材料、AI 与师生评审改进

本次沿用原 Sites 项目、R2 数据、账号密钥配置与公开访问设置，不做破坏性迁移。

## 使用路径

1. 在工作台上传材料，通过材料旁的“⋯”填写类别、版本和用途。
2. PDF 打开后点击“选择关键页供 AI 使用”，输入最多 3 个页码。PDF.js 在本页渲染 JPEG，原 PDF 保留；重复选同页会复用现有图像。
3. AI 点评中勾选材料。记录区分文字、附件内容、模型元数据、只列文件名。DeepSeek 未选页的 PDF 不宣称已读取；视觉能力由所选模型决定。
4. 结构化点评包含概览、已有依据支持的优点、材料缺口、教师候选追问和按优先级排列的问题。任一真实点评支持继续追问，每条对话最多 8 轮，保留原始材料与对话，不自动写入个人稿。
5. 模型工作台可保存最多 8 个视图书签；真实模型支持按网格显隐。保存两个包含转换结果的阶段版本后，在档案区点击“模型对照”，相机同步；坐标系变化仍需人工检查。
6. 保存快照后创建“师生评审室”，选择共享版本。邀请角色为评审教师或只读访客。教师邀请必须绑定登录邮箱；访客可绑定邮箱，也可生成持链接并登录即可加入的邀请。邀请期限为 1、7 或 30 天。
7. 教师可围绕原文段落、指定材料或模型表面提问并布置修改任务。项目所有者回应，教师复核；处理过程追加记录。共享快照不随私人工作稿变化。
8. 档案区可下载图文 HTML 报告，再用浏览器打印为 PDF。评审室报告额外附上导出当时的师生讨论，明确区别于原始快照。

## 数据与授权

- 原 `users/<id>/state.json`、文件、模型和加密 AI 连接保持原路径。
- `review-rooms/<uuid>.json` 独立保存所选快照、成员授权、邀请摘要、讨论与版本。
- 邀请使用 192 位随机 token，只存 SHA-256 摘要；可复制的完整链接只在创建结果中返回一次。
- 服务端每次读取材料、评审记录或写入讨论均校验当前账号的授权与邀请有效期。成员与邀请不能通过普通个人 state 写入。
- 共享文件代理只允许快照中列出的文件和对应不可变 GLB；不开放所有者的其他材料、私人工作稿或 AI Key。
- 写操作检查同源，评审室更新使用 R2 ETag 条件写入。过期与撤销同时约束已加入成员。
- PDF 衍生页保留源文件 ID 和页码，服务端校验源 PDF 属于同一用户、同一项目；页图由用户浏览器生成。
- AI 追问重新加载原附件并校验 SHA-256，沿用原模型截图和文字，不悄悄混入新稿。继续使用单次显式调用、幂等请求与每日限额。

## 验证范围与限制

自动检查覆盖原工作流、跨账号授权、邮箱绑定、只读权限、越权下载、撤销/过期、并发冲突、AI 冻结上下文与幂等、HTML 转义及 PDF 选页渲染。DOM 测试使用模拟浏览器；Worker 测试使用 workerd/Miniflare，AI 上游为受控响应，没有真实 Key 或计费调用。

当前环境没有可用浏览器控制工具，未进行真实浏览器的视觉检查、WebGL 操作和移动端实机验收。还需用实际 DeepSeek 账号确认额度及模型能力，并由真实师生试用。当前提供的是项目所有者授权的版本评审，不包含机构教师身份校验、全班名册、学校统一账号或自动成绩评定。VR、自动几何差异识别及多人实时相机跟随保留为后续扩展。

PDF.js 4.10.38 使用 Apache-2.0 许可，运行脚本、字体与中文 CMap 均从本站提供，无外部 CDN。构建产物生成在 ignored 路径，许可文件随发布保留。
