# DeepSeek 接入与使用

## 网站使用者

1. 打开网站，点击“登录 ChatGPT”。网站本身公开展示，个人项目与 AI 连接按登录账号隔离。
2. 点击左侧“AI 连接设置”。在密码输入框中填写自己的 DeepSeek API Key，点击“保存并验证连接”。请勿把密钥粘贴到聊天、项目汇报或源代码中。
3. 服务器向 `https://api.deepseek.com/models` 验证密钥并读取可用模型。首次优先选择 `deepseek-flash`；若不存在则使用实际可用列表。验证后可以切换模型。
4. 在共创工作台的“汇报共创”中点击“AI 起稿”，或在“AI 点评”中发起点评。生成前先选择依据文件，再明确点击生成。
5. 审阅结果后，选择“保存到初稿参考区”或“加入点评列表”。初稿不会覆盖学生个人稿；需要时明确点击“加入个人稿后改写”。新点评追加到原列表，旧回应继续保留。
6. 对真实点评可点击“围绕这条点评继续追问”，沿用原始材料，最多 8 轮；每次计入当日生成限额。新增材料后请发起新一轮点评。
7. 在生成记录中查看当时的文字、所选材料、模型视图、服务、模型、token 用量和结果。失败或网络中断不会自动重试，避免重复调用。

API 使用 DeepSeek 账号的额度，每个账号每天最多 10 次生成尝试（按北京时间日期计算）。这是站内限制，不能代替服务商账号的预算与消费管理。

## 实际提供给 AI 的材料

- 保存的项目背景、设计目标、使用者、课程任务、教师关注点。
- 个人汇报各段、学生改写理由、材料依据和反思。
- 用户明确勾选的模型元数据、JPG/PNG 图纸和当前真实模型的轴测／俯视／正视图。
- 是否支持图片从所选模型官方元数据确认；未声明图片输入时，只发送文字及文件清单。
- SKP 二进制不直接发送，使用已转换模型的元数据与用户选中的有限视角。
- 当前 DeepSeek 接口不直接读取 PDF 原件。可在本站选择 PDF 关键页保存为 JPEG，再勾选这些图像参与点评；未选页的 PDF 仅提供文件清单。
- 图片总量不超过 4 MB，含模型视图的总输入预算为 5 MB；每次最多选择三份文件。

所有材料都视为待分析的数据。系统提示明确要求不执行材料中的指令、不虚构测量或场地数据、证据不足时提出待验证问题，不推断作者身份或“AI 使用概率”。模型返回内容经结构校验与文字引文校验，页面按文本转义展示。

## 密钥与权限

用户 API Key 只通过本站同源 HTTPS 接口提交，在后端调用官方模型列表验证后，以 AES-256-GCM 加密存入该用户独立的 R2 目录。每次保存使用随机 12 字节 IV，关联数据绑定用户目录与密钥格式版本。GET 接口只返回遮罩、模型和验证时间，不返回明文密钥。

加密主密钥由 Sites 的 secret 环境变量 `AI_SECRET_ENCRYPTION_KEY` 管理，不在源码、静态 HTML、项目状态或浏览器存储中。公开网站的其他访问者不能调用其他账号的连接或读取生成记录。用户可以断开连接，移除当前保存的密钥；原作品和生成记录保留。

主密钥不得在存在用户连接时直接替换。需要轮换时应先实现解密和重新加密的迁移流程；直接更换会令现存连接无法读取。

## 运行配置

- `AI_PROVIDER=deepseek`。
- `AI_DAILY_LIMIT=10`，可在 1–50 范围配置。
- `AI_SECRET_ENCRYPTION_KEY`：32 个随机字节的 Base64 编码，必须为 Sites secret。
- 可选共享配置：`DEEPSEEK_API_KEY`（secret）、`AI_MODEL` 和 `AI_ALLOWED_EMAILS`。共享密钥只对明确允许的登录邮箱开放；个人连接优先使用本人的密钥。当前上线采用个人连接方式，未配置共享 DeepSeek 密钥。

调用端点固定为 `https://api.deepseek.com/chat/completions`，JSON 输出、非流式、关闭思考模式，以适应课程交互。调用输出上限 3600 tokens、服务超时 65 秒；不请求或展示模型的推理内容。密钥、服务商原始错误详情和任意 URL 代理均不向客户端暴露。

## 数据与版本

连接位于 `users/<userId>/ai/connection.json`（密文）。生成记录位于同一用户目录的 `ai/runs/<requestId>.json`，每项目有独立索引。生成不自动写入项目，保存结果时检查 ETag 与材料指纹；材料已修改时不能把旧结果写入新汇报。客户端普通项目保存不能覆盖已保存的 AI 证据和生成来源，仍可更新学生回应和问题状态。

## 验证范围

自动检查覆盖密钥加密和断开、跨用户隔离、CSRF、官方请求结构、JSON 校验、图像输入、引文与来源、幂等、保存冲突、异常不覆盖、独立初稿及旧点评保留。DOM 回归检查完成了连接设置 → 验证 → 点评预览 → 追加点评 → 起稿 → 写入参考区 → 主动加入个人稿 → 历史记录 → 断开连接。

这些检查使用受控服务响应，没有使用用户的真实 DeepSeek API Key，也未产生真实推理调用费用。线上模型质量、余额权限和真实材料上的输出仍需在用户完成连接后验证。独立下载 HTML 的旧离线版本不包含此次在线 API 服务。

## Cloudflare Worker 请求兼容性修复

连接验证与生成请求使用 `redirect: manual`，显式拒绝 3xx，不向重定向目标转发密钥或材料。原先使用的 `redirect: error` 在 Cloudflare Workers 中会在发出网络请求前抛出 TypeError，导致被错误归类为网络连接失败。

已在 Miniflare/workerd（该安装版本支持的兼容日期为 2026-08-06）复现原请求返回 504 且没有发出上游请求；修复后验证模型、密钥加密存储和生成记录链路通过，且重定向仍被拒绝。运行时测试使用受控的上游响应，不涉及用户真实 API Key 或付费推理。Node 回归测试同样检查这两个请求的重定向设置，并覆盖验证和生成接口收到 3xx 的情况。
